# Шиншилла рядом — iOS-приложение

Небольшой SwiftUI-прототип для ежедневного наблюдения за шиншиллой: состояние, заметки, вес и напоминания об уходе. Данные хранятся локально на устройстве.

## Возможности
- Карточка питомца и сводка за день.
- Журнал наблюдений: аппетит, активность, стул, вода и свободная заметка.
- История веса с датами.
- Список дел по уходу с отметками выполнения.
- Подсказки по наблюдению и напоминание обратиться к ветеринару при тревожных симптомах.

> Приложение не ставит диагноз и не заменяет ветеринарного врача. При отказе от еды, затрудненном дыхании, резкой вялости или других острых симптомах обратитесь к ветеринару по экзотическим животным.

## Запуск на iOS

Требуется Mac с актуальным Xcode (для запуска на iPhone нужен Mac; на Windows/Linux собрать iOS-приложение штатными средствами нельзя).

1. В Xcode выберите **File → New → Project → iOS → App**.
2. Назовите проект `ChinchillaCare`, выберите **SwiftUI** и **Swift**.
3. Замените содержимое созданного `ContentView.swift` файлом `ContentView.swift` из корня этого репозитория. Замените файл приложения `...App.swift` содержимым `ChinchillaCare/ChinchillaCareApp.swift`.
4. В настройках Target → **General** задайте Deployment Target iOS 16 или новее.
5. Выберите симулятор iPhone в верхней панели Xcode и нажмите ▶︎ (или **Product → Run**).
6. Для запуска на реальном iPhone подключите его кабелем, выберите устройство, в **Signing & Capabilities** включите **Automatically manage signing** и выберите свой Team/Apple ID. Нажмите ▶︎ и подтвердите доверие разработчику на телефоне, если iOS попросит.

Для установки через TestFlight или App Store потребуется аккаунт Apple Developer и архивирование приложения в Xcode (**Product → Archive**).
