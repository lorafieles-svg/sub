# ОТКЛИК — звук, который слышит ваше дыхание

> **Дыши — и мир ответит.**
> Адаптивная среда для регуляции состояния: генеративный звук идёт за вашим дыханием,
> затем медленно ведёт вас к вашему личному ритму покоя — и замолкает, когда вы справляетесь сами.

В репозитории — **концепция, полное ТЗ, бизнес-модель и рабочий прототип** главной механики.
Никакой библиотеки медитаций. Ноль загружаемого аудио. Всё синтезируется и обрабатывается на устройстве.

## Прототип

```bash
python3 demo/server.py 8000      # http://localhost:8000
```

`demo/server.py` — мини-сервер для превью: `no-store` (правки видны сразу, без кеша), правильные MIME для js/css/audio, CORS для встраивания в iframe. Обычный `python3 -m http.server` тоже работает, но кеширует агрессивнее.

Можно открыть и просто `demo/index.html`, но для микрофона нужен безопасный контекст — `http://localhost` или `https`.

**Что реально работает:**
- синтез звука в Web Audio — не файлы: саб, дрон, пэд, воздух, генеративный реверб;
- дыхание считывается микрофоном (RMS-огибающая 150–2600 Гц, гистерезис, адаптивный шумовой порог);
- звук и визуал реагируют на вдох/выдох с задержкой ~100–300 мс;
- «минуты до покоя» считаются по факту входа в целевой коридор;
- **библиотека сред и микшер**: 10 слоёв (море, ручей, дождь, птицы, ветер, сверчки, костёр, гроза, поезд, кафе), у каждого своя громкость, любое число одновременно, предпрослушивание, сохранённые среды;
- **свои звуки**: любой mp3/wav/ogg как слой среды — декодируется, нормализуется, зацикливается и остаётся только на устройстве (IndexedDB);
- **настройки звука**: громкость, «отклик» (сила влияния дыхания), бас, тембр, размер пространства;
- «отпечаток» собирается из сессий и хранится локально;
- без микрофона продукт продолжает работать в режиме ведения по такту.

**Что упрощено относительно ТЗ:** нет верификации резонансной частоты по 4 сессиям (в демо — оценка по средней частоте),
нет live-комнат, «Голоса близкого», ночного режима и биллинга. Всё это описано в ТЗ, но не входит в прототип ядра.

## Пять механик, которых нет ни у кого

1. **Зеркало.** 90 секунд без инструкций: звук идёт за вашим дыханием. Онбординг без анкеты и пейволла.
2. **Ведение.** Звук перестаёт зеркалить и очень медленно замедляет вас до *вашей* резонансной частоты (4,5–7,0 вдохов/мин — она индивидуальна, а не «6 для всех»).
3. **Пространство.** Финал сессии — тишина. Приложение не должно становиться костылём.
4. **Отпечаток.** Личная формула покоя: частота, тембр, длительность, время. Каждая сессия делает следующую точнее.
5. **Общая волна.** Анонимные live-комнаты: сервер рассылает только фазовые тики, звук каждый синтезирует у себя. Ноль трафика, идеальная приватность, бесконечный масштаб.
6. **Среда и микшер.** Море, птицы, сверчки, костёр, гроза — не треки, а слои-текстуры, которые дышат вместе с вами. Плюс свои файлы: дождь с вашего балкона как слой.

## Чем это отличается от Calm / Headspace / Breathwrk

| | Категория | ОТКЛИК |
|---|---|---|
| Контент | Тысячи аудиофайлов, паралич выбора | Ноль файлов: процедурный синтез под вас |
| Связь с пользователем | Никакой | Звук ведом вашим дыханием |
| Ритм | Один паттерн для всех | Персональная резонансная частота |
| Удержание | D30 ≈ 5–6% | Цель: D30 ≥ 10% за счёт «минут до покоя», которые падают |
| Мотивация | Стрики и вина | Анти-стрик: приложение хочет быть ненужным |
| Себестоимость контента | Гонорары, студии, лицензии | ≈ 0 |
