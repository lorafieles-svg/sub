# «ОТКЛИК» — функциональное ТЗ

Версия 1.0 · Продукт: iOS / Android (React Native) + веб-демо · Язык интерфейса: RU, далее EN, ES, PT-BR

---

## 0. Принципы, из которых вытекает всё остальное

1. **Ноль решений на входе.** Пользователь не выбирает «что послушать». Максимум один выбор — длительность.
2. **Нет провала.** Нет красных шкал, нет «вы дышите слишком быстро», нет прерванных сессий с надписью «незавершено».
3. **Тишина — цель.** Любая сессия стремится к уменьшению вмешательства.
4. **Один тап после.** Любая обратная связь — один тап. Всё остальное опционально.
5. **Приватность видима.** Индикатор микрофона, статус «на устройстве», выключатель.

## 2. Информационная архитектура

```
[Заставка]
   └─ Первый запуск
        ├─ Экран-обещание (1 фраза + «Начать») ← пейволла нет
        ├─ Скрининг-вопрос (1 экран, 1 вопрос)
        └─ СЕССИЯ 1 «Зеркало» (90 сек)
             └─ «Вы только что услышали своё дыхание»
                  ├─ [Результат + один тап]
                  └─ [Дом]

[Дом]  ← единственный «хаб», без лент
   ├─ Большая кнопка «Дышать» (по умолчанию = рекомендованная сессия)
   ├─ Строка состояния: «Сейчас вам подойдёт: 3 мин · ведение · 5,5/мин»
   ├─ Чипсы: 90 сек · 3 мин · 5 мин · 10 мин · Ночь
   ├─ Строка «среда: Море + Ветер» (тап → Мастерская звука)
   ├─ «Отпечаток» (прогресс, 1 экран, тап → детали)
   ├─ «Общая волна» (сейчас онлайн: 4 127)
   └─ Тихая строка: «Настройки · Приватность · Помощь»

[Сессия]
   ├─ Фазы: Зеркало → (Поиск резонанса) → Ведение → Пространство → Тишина
   ├─ Оверлей «Стоп» (всегда)
   └─ Финал → [Результат]

[Результат]
   ├─ «Минуты до покоя: 2,4» + дельта к прошлой
   ├─ Один тап: спокойнее / так же / хуже
   ├─ «Сохранить в отпечаток»
   ├─ (опц.) голосовая заметка 10 сек / строка текста
   └─ «Поделиться дыханием» (премиум)

[Отпечаток]
   ├─ «Ваша формула: 5,4 вдоха/мин · низкий бас · 3 мин · 08:30–10:00»
   ├─ График «минуты до покоя» за 30/90 дней
   ├─ «Что вам помогает» (топ-3 параметра)
   ├─ «Что не помогает» (честно)
   └─ Экспорт / сброс

[Общая волна]
   ├─ Выбор комнаты: Сейчас · Перед сном · Для тревоги · Хор
   ├─ Счётчик присутствия (анонимный)
   ├─ Фазовое поле (визуализация дыхания всех)
   └─ «Дышать вместе» → сессия с общим тактом

[Мастерская звука]
   ├─ Название среды (генерируется само)
   ├─ [Слушать среду] — предпрослушивание по идеальному дыханию
   ├─ Слои по группам: Вода · Лес · Ночь · Огонь · Погода · Город · Мои звуки
   │    каждый: иконка, название, вкл/выкл, ползунок громкости
   ├─ «+ добавить свой звук» (файл → локальное хранилище)
   ├─ Сохранённые среды (чипсы, удаление)
   └─ [Дышать с этой средой]

[Между] — микро-ритуалы
[Ночь] — проводник до порога
[Настройки]
   ├─ Звук (громкость баса, тембр, «мягкий режим»)
   ├─ Микрофон (вкл/выкл, чувствительность, «карманный режим»)
   ├─ Голос (мой голос / близкого / без голоса)
   ├─ Уведомления (только «Между», по умолчанию ВЫКЛ)
   ├─ Приватность и данные (экспорт, удаление)
   └─ Подписка
```

Экран «Дом» — один, без скролла на типичном телефоне. Всё остальное — вглубь.

## 3. Функциональные требования

Формат: **F#. Название** → описание, состояния, критерии приёмки (AC).

### F1. Первый запуск и онбординг (нулевой)
**Флоу:** 1 экран обещания (1 предложение + кнопка «Дышать») → **шторка «Нам нужен микрофон»**: три пункта обещания (работает только во время дыхания · индикатор на экране · можно отказаться) + единственный вопрос скрининга («Бывает, что дыхание вызывает панику?») + кнопки «Дышать» и «начать без микрофона» → системный запрос → сессия «Зеркало» → результат.

Отказ от микрофона — валидный путь: продукт переходит в режим ведения и больше не спрашивает.

**Правила:**
- Нет регистрации, e-mail, пароля, соцлогина. Аккаунт создаётся анонимно (device-id → серверный анонимный профиль).
- Нет выбора языка/цели/уровня опыта.
- Нет пейволла до 3 завершённых сессий.
- Если пользователь отказал в микрофоне — предлагается режим «Ведём вас» (без зеркала) с возможностью включить позже; продукт остаётся работоспособным.

**AC:** пользователь, впервые открывший приложение, оказывается в звучащей сессии не более чем через **2 тапа и 15 секунд**.

### F2. Скрининг безопасности (1 вопрос)
Экран: «Бывает ли, что дыхательные упражнения вызывают у вас панику или головокружение?» → `Да / Иногда / Нет`.
- `Да/Иногда` → включается **«мягкий режим»**: без задержек, только 4-6 дыхание, пауза на выдохе ≤ 1 сек, кнопка «Стоп» подписана «Остановиться, если неприятно», в начале сессии — подсказка «Дышите тише и меньше, чем кажется правильным».
- Дополнительно: постоянная ссылка «Помощь» с телефонами доверия (по региону), видимая в настройках и в результате сессии, если выбрано «хуже».
- Возраст: 16+ (13+ с «подростковым» профилем в v2, с согласием).

**AC:** при `Да` ни в одном паттерне сессии не встречается задержка дыхания > 1 с.

### F3. Сессия «Зеркало» (Mirror)
**Вход:** кнопка «Дышать», длительность 90 сек (или первая фаза любой сессии).
**Поведение:**
- Микрофон 16 кГц моно, обработка на устройстве.
- Из RMS-огибающей определяется фаза: `вдох / выдох / пауза`; латентность < 300 мс.
- Аудио-параметры привязаны к огибающей: громкость баса, срез ФНЧ, ширина стерео, уровень реверба.
- Визуал: сфера/кольцо, дышащее вместе с пользователем (и с реальным дыханием, а не с таймером).
- Если 4 секунды нет сигнала — деликатная подсказка «Дышите чуть слышнее» (не ошибка).

**AC:** при дыхании с амплитудой выше порога шума аудио визуально и на слух реагирует не позже 300 мс; при отсутствии сигнала сессия не прерывается и продолжает работать в авто-режиме.

### F4. «Поиск резонанса» (RF-finding)
**Зачем:** резонансная частота индивидуальна (≈4,5–7,0 вдохов/мин) и меняется; фиксированные 6/мин или 4-7-8 подходят не всем.

**Протокол (проходит незаметно, встроен в первые 3–5 сессий):**
1. Каждая сессия ведёт на одной «пробной» частоте из сетки: 4,5 · 5,0 · 5,5 · 6,0 · 6,5 · 7,0 вдохов/мин.
2. Во время сессии считаются метрики: **стабильность периода** (CV интервалов вдох-вдох), **глубина** (амплитуда огибающей), **число «сбоев»** (вдохи вне такта), **субъективный отклик** (тап после).
3. После 4 сессий модель выбирает частоту: `score = w1·стабильность + w2·глубина + w3·субъективный отклик − w4·сбои`.
4. Частота закрепляется как «ваша» и пересчитывается раз в 2 недели (если меняется — приложение говорит об этом одной строкой).

**AC:** после 4 сессий в «Отпечатке» отображается персональная частота с точностью 0,5 вдоха/мин; пользователь всегда может переопределить вручную.

### F5. Сессия «Ведение» (Lead)
- Целевая частота = `f(резонанс, текущий ритм, цель, время суток)`.
- Стартовая частота = ваш текущий ритм (округлённый), спуск: −0,3–0,5 вдоха/мин каждые 30 сек, не более 8 шагов.
- Соотношение вдох:выдох = 1:1,5 → 1:2 (выдох длиннее — парасимпатика); в «мягком режиме» 1:1,2.
- Ведение **не заставляет**: если пользователь дышит быстрее такта, звук подстраивается, а не «ругается»; через 20 секунд попытки синхронизации — предложение остаться в зеркале.
- Голосовое сопровождение — **опционально и по умолчанию выключено**. По умолчанию — только звук и визуал.
- Длительность: 90 сек / 3 / 5 / 10 / 20 мин.

**AC:** ни в одном состоянии UI нет сообщения об ошибке дыхания; пользователь может прервать в любой момент, сессия сохраняется как завершённая с флагом `partial`.

### F6. «Пространство» и финал в тишине
- Последние 20% длительности (не более 60 сек) — целевая громкость уходит к 5–8%, остаётся только низкий гул и воздух.
- Финал: никакого гонга, никакого «сессия завершена». Экран плавно светлеет, появляется результат.
- Если пользователь не двигался 3 минуты после финала — экран гаснет, приложение не издаёт звуков.

**AC:** после финальной ноты в аудио-графе остаётся тишина; ни один системный звук приложения не воспроизводится вне сессии.

### F7. Результат сессии и один тап
**Экран:** «Минуты до покоя: 2,4 ↓0,3» (крупно), три кнопки: `спокойнее` / `так же` / `хуже`.
- «Минуты до покоя» = время от старта сессии до момента, когда (а) частота дыхания вошла в целевой коридор и удержалась 30 сек, и (б) амплитуда стала стабильной. Если не достигнуто — показываем «не измерено» + мягкий текст.
- При `хуже` → предложение «Остановиться и подышать в мягком режиме?» + ссылка на помощь.
- Опционально: голосовая заметка 10 сек или строка (не обязательна, не блокирует).
- Дальше: «Продолжить в отпечаток» / сразу домой.

**AC:** весь экран результата проходится одним тапом; приложение никогда не требует второй тап, чтобы закрыть экран.

### F8. «Отпечаток спокойствия»
**Содержимое:**
- Формула: `5,5 вдоха/мин · тёмный тембр · 3 мин · утро`.
- График «минуты до покоя» (30/90 дней) + медиана.
- «Работает» — топ-3 фактора, «Не работает» — топ-2 (честно, это доверие).
- Сравнение с анонимной когортой («вы быстрее среднего на 0,8 мин») — опционально, выключено по умолчанию.
- Экспорт (JSON/PDF) и «сбросить модель».

**Модель:** см. `02-ТЗ-ТЕХНИКА.md §5`. Клиентская персонализация + серверное обучение; всё, что нужно для сессии, доступно офлайн.

**AC:** отпечаток обновляется после каждой сессии; при <3 сессиях показывается прогресс «нужно ещё N сессий», без фейковых данных.

### F9. «Общая волна» (Live Rooms)
**Механика:** сервер держит фазовые часы (epoch + период). Клиенты синтезируют звук локально по этим часам. Сервер рассылает тики 1/сек и агрегат (число участников, средняя частота).
**Комнаты:** «Сейчас» (свободный такт), «Перед сном» (медленнее), «Для тревоги» (мягкий режим), «Хор» (гул, в v2).
**Социальное:** только счётчик и фазовое поле. Ни имён, ни аватаров, ни чата, ни «спасибо». Можно «помахать» — отправить анонимный тёплый импульс в поле (без адресата).
**Персональное:** рядом с общей волной — ваша личная дорожка (если вы отклонились, вас никто не видит и вы никого не портите).
**Расписание:** «общие волны по расписанию» (21:30 ежедневно, 8:00 по будням) — событийный крючок без стрика.

**AC:** при 10 000 участниках сервер отдаёт < 2 КБ/сек на клиента; рассинхронизация фаз < 150 мс.

### F10. «Голос близкого» (Voices) — премиум
1. Пользователь записывает 60–90 сек нейтрального текста (или загружает аудио) — **своего** голоса или голоса близкого.
2. Если голос не свой — обязательный шаг **согласия**: экран с текстом, чекбокс «у меня есть разрешение», ввод имени владельца голоса, и **фраза-подтверждение, произнесённая владельцем** (liveness) — «Я разрешаю использовать мой голос в приложении Отклик».
3. Клонирование на сервере (TTS-провайдер), не более 3 голосов на аккаунт.
4. Все синтезированные фразы — из заранее утверждённого безопасного набора (≈40 фраз); **свободный ввод текста в чужом голосе запрещён навсегда** (анти-дипфейк).
5. Отзыв согласия — в 1 тап, модель удаляется в течение 24 часов, отчёт об удалении показывается.
6. Аудио помечается водяным знаком/метаданными C2PA.

**AC:** без пройденной фразы-подтверждения клонирование невозможно ни через API, ни через клиент.

### F11. «Гул» (Hum)
- Пользователь тянет «ммм» на выдохе; микрофон определяет высоту (F0, 60–400 Гц) и приложение добавляет 2–3 гармонических голоса в этой тональности.
- Визуал: спектр в виде расходящихся кругов.
- Режимы: «один» (соло с гармонией), «хор» (общая волна).
- В «мягком режиме» — без задержек и без требований к длительности.

### F12. «Между» (микро-ритуалы)
- Триггеры: **календарь** (событие закончилось / следующее через 5 мин), **время суток** (первое открытие телефона утром, вечер), **движение** (в пути), **ручной виджет**.
- Формат: 60–90 сек, 3 вдоха, «мягкий режим» по умолчанию.
- Максимум 2 триггера в день. Никаких «вы давно не заходили».
- Требует явного разрешения на календарь; работает без него.

**AC:** приложение ни при каких настройках не отправляет больше 2 уведомлений в сутки.

### F13. «Ночь» (проводник до порога)
- Экран: «Положите телефон рядом. Мы замолчим, когда вы уснёте.»
- Микрофон слушает; детектор засыпания: частота дыхания стабильна и снизилась, амплитуда падает, микродвижения (акселерометр) отсутствуют, отсутствие речи ≥10 мин.
- При срабатывании: звук уходит в 0 за 60 сек, экран гаснет, микрофон выключается, сессия помечается «сон, N мин».
- Ничего не пишется и не передаётся; утром — одна строка: «Заснули за ~14 минут. Хорошее утро?» (один тап).
- Аккумулятор: аудио-обработка на пониженной частоте дискретизации, рекомендуется «на зарядке».

**AC:** при срабатывании детектора микрофон выключается полностью (проверяется индикатором ОС и телеметрией).

### F14. «Карманный режим» / вибрация
- Ритм передаётся паттерном вибрации (вдох — нарастание, выдох — спад).
- Доступно на iOS (Core Haptics) и Android (VibrationEffect).
- Работает при заблокированном экране? — Нет (ограничение ОС), но с включённым экраном и в кармане через наушники-кости — да (v2, партнёрство).

### F15. Уведомления
Разрешены только:
- «Между» (по календарю/времени, максимум 2/день, по умолчанию выкл.);
- «Общая волна через 10 минут» (по подписке на расписание, по умолчанию выкл.);
- технические (оплата, безопасность).
**Запрещены навсегда:** «вы давно не заходили», «не потеряйте серию», «новый контент», любые эмодзи-солнышки.

### F16. Подписка и пейволл
**Бесплатно навсегда:** зеркало, 1 сессия ведения в день (3 мин), базовый звук (1 тембр), отпечаток (сводка), «Между».
**Премиум «Отклик+»:** все длительности и режимы, все тембры/среды, «Голос близкого», «Ночь», «Общая волна», «Гул/Хор», расширенный отпечаток, офлайн-паки, до 5 членов семьи.
**Пейволл:** после 3-й завершённой сессии, в конце сессии, с честным экраном «Что вы получите» + «Что остаётся бесплатным». Триал 7 дней без «скидки, которая исчезнет через 60 секунд».
**Гарантия:** «Если за 30 дней минуты до покоя не снизились — вернём деньги, без переписки». (Реализуется как авто-refund по запросу в приложении.)

### F17. Настройки звука
- Тембр: `тёмный / нейтральный / светлый` (по сути — спектральный наклон).
- Бас: −6…+6 дБ.
- Стерео-ширина, «наушники/динамик» (кроссфид для динамика).
- «Тихий старт» — начинать с очень низкой громкости.
- «Голос» — вкл/выкл, выбор голоса.
- Проверка наушников (тест левого/правого).

### F18. Приватность и данные
- Экран «Что мы знаем о вас»: список полей, кнопки «экспорт» и «удалить всё» (без писем в поддержку, в 2 тапа).
- Микрофон: строка статуса «обрабатывается на устройстве · не записывается».
- Ноль сторонних SDK аналитики с рекламными целями; аналитика — self-hosted/или privacy-first.

### F19. Доступность
- VoiceOver/TalkBack: все экраны; сессия полностью управляема без зрения (аудио-подсказки фаз — по настройке «озвучивать фазы» шёпотом).
- Динамический шрифт, контраст ≥ 4.5:1, reduce motion (статичный визуал), вибро-дублирование фаз.
- Субтитры/текст для всех голосовых гайдов.
- Работа в самолётном режиме (всё, кроме live и голоса).

### F20. B2B-кабинет (веб)
- Админ компании: список приглашённых по e-mail/домену, использование **в агрегатах** (≥10 человек в срезе, иначе скрыто), отчёт PDF.
- Запрещено: видеть индивидуальные сессии, дыхательные данные, ответы на опросы.
- Программа: 4-недельный курс «Стресс-гигиена» + «Между» + еженедельная общая волна для компании.
- SSO (SAML/OIDC) в v2; на старте — доменные инвайты.

### F21. Библиотека сред (Layered Ambience)
Звук «Отклика» — не одна дорожка, а **стек из независимых слоёв**, которые смешиваются в реальном времени. Дыхание остаётся дирижёром: все слои дышат вместе с ним, но каждый — со своей фактурой.

**Базовый каталог v1 (10 сред, 6 групп):**

| Группа | Слои | Характер |
|---|---|---|
| Вода | Море, Ручей, Дождь | медленные волны, «пена» на гребне, капли |
| Лес | Птицы, Ветер | редкие птичьи фразы, ветер в кронах |
| Ночь | Сверчки | стрекотание с фазовым разбросом |
| Огонь | Костёр | низкий гул + треск |
| Погода | Гроза | дождь + далёкий гром |
| Город | Поезд, Кафе | ритм колёс, приглушённый говор |

**Требования:**
- Любое количество слоёв одновременно, у каждого — независимая громкость 0–100%.
- Ползунок на 0 = слой останавливается (не «играет в тишине»), возврат — плавный fade 250 мс.
- Среда **не перебивает** дыхание: суммарный уровень среды ниже генеративной основы, а в фазе «Пространство» среда уходит на −88%.
- Все среды работают офлайн, вес приложения не растёт (синтез, а не файлы).
- Беззвучный режим: среда выключена, остаётся только «дыхательный» слой — это легальный выбор, не «неполный» опыт.

**AC:** при включении 6 слоёв одновременно суммарный пик не превышает −1 dBTP (лимитер), CPU ≤ 10% на среднем устройстве, переключение слоя слышно не позже 400 мс.

### F22. Мастерская звука (микшер)
Экран «Мастерская звука» — единственное место продукта, где пользователь **что-то настраивает**. Доступен с главного экрана одним тапом, а также как замена «выбора медитации»: вместо выбора трека — сборка своей среды.

**Функции:**
1. **Список слоёв** с иконкой, названием и ползунком; тап по названию = вкл/выкл.
2. **Название среды формируется само** из трёх самых громких слоёв («Море + Ветер»). Никакого ввода текста.
3. **Предпрослушивание** без сессии: среда звучит по «идеальному» дыханию 6/мин, чтобы можно было оценить баланс до старта.
4. **Сохранённые среды:** «Берег», «Лес утром», «Ночь у огня», «Дождь» + ваши собственные. До 12 пользовательских. Сохранение одним тапом «сохранить среду».
5. **«Дышать с этой средой»** — переход сразу в сессию.
6. Превью автоматически останавливается при уходе с экрана (никогда не играет «в фоне»).

**AC:** состояние микшера переживает перезапуск приложения; сохранённая среда воспроизводится идентично (те же уровни ±1%).

### F23. Свои звуки (Custom Layers)
Возможность добавить **свой** аудиофайл как слой среды.

**Правила:**
- Форматы: mp3, wav, ogg, m4a; до 12 МБ и до 10 минут.
- Файл декодируется, нормализуется по громкости, бесшовно зацикливается (кроссфейд 350 мс) и сохраняется **локально в IndexedDB**. На сервер не уходит — это принципиально (пользовательские записи могут содержать голоса близких).
- Имя слоя = имя файла (обрезается до 28 символов); удаление — в один тап с подтверждением.
- Слой ведёт себя как встроенный: ползунок, среда, сохранение, участие в сессии.
- Взрослый контент/чужие треки — ответственность пользователя; в интерфейсе — короткая честная приписка «используйте свои записи или файлы, на которые у вас есть права».

**AC:** добавленный файл звучит без щелчков на стыке петли; после перезагрузки страницы/приложения слой на месте; при удалении приложения файл исчезает вместе с данными.

### F24. Настройки звука: расширенный набор
| Параметр | Диапазон | Смысл |
|---|---|---|
| **Громкость (общая)** | 10–100% + mute | один мастер на всё приложение, доступен и в сессии (F25) |
| **Отклик** | 35–160% | насколько сильно дыхание модулирует звук. 35% — почти ровный дрон для тех, кого укачивает; 160% — выраженная волна |
| Бас | −6…+6 дБ | «телесность» |
| Тембр | тёмный / нейтральный / светлый | спектральный наклон и тональность |
| Пространство | комната / зал / открытое | длина реверба (1,4 / 2,6 / 4,4 с) |
| Микрофон | вкл/выкл | отказ не ломает продукт |
| Мягкий режим | вкл/выкл | без задержек, короче выдох |
| Вибрация | вкл/выкл | такт в кармане |
| Для динамика телефона | вкл/выкл | срез низа 130 Гц + приглушение баса, чтобы не «бубнило» |
| Тихий старт | вкл/выкл | первые 20 секунд вполголоса |
| Тест наушников | кнопка | тон в левый, затем в правый канал |

Изменения уровня и микшера применяются **немедленно**; тембр и пространство — со следующей сессии (без разрыва текущей), о чём приложение сообщает одной строкой.


### F25. Общий регулятор громкости (Master Volume)
Громкость — **одна на всё приложение**, а не «на каждую сессию».

**Требования:**
- Доступна в трёх местах: (1) внутри сессии — постоянный слайдер рядом с кнопкой mute, (2) в настройках, (3) аппаратные кнопки громкости устройства работают как обычно.
- Уровень применяется **мгновенно и без щелчков** (`setTargetAtTime`, τ = 80 мс), в том числе во время звучания.
- Значение и mute сохраняются между запусками; новое устройство начинает с 60% (не с 100% — это бережёт слух).
- Mute — отдельное состояние: он не стирает уровень, а после включения звук возвращается на прежнюю громкость.
- Потолок: мастер-гейн ≤ 0,78 + лимитер −1 dBTP. Приложение никогда не играет «на всю».
- Изменение громкости не влияет на таймер, фазы и «минуты до покоя».
- Клавиатурные сокращения: ↑/↓ — шаг 5%, M — mute.

**AC:** изменение слайдера слышно не позже 150 мс и не даёт щелчка; после перезапуска уровень совпадает с последним; при mute = 0 дБ на выходе, но сессия продолжает идти.

### F26. Управление сессией (пауза, продление, среда)
Лучшая практика таких приложений — сессия не должна быть «хрупкой».

- **Пауза / продолжить.** Аудио уходит в 0 за 250 мс, таймер останавливается; после снятия паузы время сессии сдвигается — пауза **не съедает** длительность. Визуал приглушается, подсказка меняется на «пауза».
- **Продлить.** Кнопка «+2 мин» на экране сессии; фазы пересчитываются автоматически, «Пространство» сдвигается.
- **Среда в сессии.** Шторка поверх сессии: пресеты + ползунки слоёв + мягкий режим. Всё применяется плавно, сессия не прерывается.
- **Мягкий режим на лету.** Переключение меняет соотношение вдох/выдох немедленно.
- **Выход** — всегда одна кнопка, сессия сохраняется как `partial`, без «провала».
- **Сбои системы.** Если ОС приостановила аудио (звонок, другое приложение), сессия автоматически ставится на паузу и предлагает продолжить, а не теряется.

**AC:** после паузы 40 секунд сессия завершается ровно по плановой длительности; при смене среды во время дыхания не слышно щелчков и сбоев фазы.

### F27. Экран, локскрин и фон
- **Wake Lock:** во время сессии экран не гаснет (там, где API доступно).
- **Media Session:** на локскрине и в наушниках видны «Отклик — дыхание» и название среды; кнопки play/pause/stop управляют сессией.
- **Фоновая вкладка/приложение:** сессия продолжает идти по реальному времени (rAF заменяется таймером), не «замерзает» и корректно завершается.
- **Прерванный звук:** при возвращении фокуса уровень восстанавливается плавно, без резкого скачка.
- **Системные жесты** не блокируются; приложение не играет вне сессии.

**AC:** в скрытой вкладке таймер сессии идёт и сессия завершается; кнопка паузы на локскрине работает; после возврата из фона звук не «прыгает».

## 4. Ключевые пользовательские сценарии (end-to-end)

**С1. Первый запуск (целевое время до первого звука — 15 сек)**
Открытие → «Дыши — и мир ответит» → [Дышать] → объяснение микрофона → системный запрос → Зеркало 90 сек → «Вы только что услышали своё дыхание» → тап «спокойнее» → «Завтра покажем вашу формулу».

**С2. Пауза посреди сессии**
Дыхание → звонок → пауза одним тапом (или автоматически, если ОС приглушила звук) → звонок → «продолжить»: сессия идёт дальше с того же места.

**С2a. Тревога перед созвоном (90 сек)**
Push «Между» (или виджет) → сессия 90 сек в мягком режиме → возврат в календарь. Никаких экранов между.

**С3. Вечер, 5 минут**
Дом → «Дышать» (приложение само ставит 5 мин, ведение, тёмный тембр, 5,5/мин) → сессия → результат → «Отпечаток».

**С4. Ночь**
Дом → «Ночь» → телефон на столе → засыпание → утро: одна строка.

**С5. Тревожный эпизод в метро**
Виджет на локскрине → «карманный режим» → вибрация 3 минуты → стоп.

**С6. Хочу свой звук**
Главная → «мастерская звука» → «+ добавить свой звук» → выбор файла (запись дождя со своего балкона) → слой появился с громкостью 50% → «сохранить среду» → «Дышать с этой средой».

**С7. Хочу вместе со всеми**
Дом → «Общая волна» → комната «Сейчас» → 4 127 человек → сессия в общем такте.

## 5. Состояния и краевые случаи (обязательно к реализации)

| Ситуация | Поведение |
|---|---|
| Нет разрешения на микрофон | Режим «ведём вас»; баннер «Включить микрофон, чтобы слышать дыхание» |
| Микрофон занят другим приложением (звонок) | Пауза, баннер «Звонок? Вернёмся, когда закончите», авто-возобновление через 3 сек |
| Очень шумно (метро, вентилятор) | Детектор SNR; при SNR < порога — «Ведём вас» + вибро, без сообщений об ошибке |
| Пользователь задержал дыхание (тревога) | Через 8 сек тишины — мягкая подсказка «Можно выдохнуть»; звук уходит в поддерживающий гул |
| Экран заблокирован во время сессии | Аудио продолжается (фоновый режим), микрофон — по настройке «продолжать при заблокированном экране» (по умолчанию да, для iOS — с индикатором) |
| Входящий звонок | Аудио плавно уходит в 0 за 0,3 с, сессия на паузе, после — возврат или завершение (`partial`) |
| Bluetooth-наушники отключились | Переключение на динамик с кроссфидом, громкость −6 дБ |
| Разряжен телефон (<10%) | Предложение короткой сессии 90 сек, отключение визуала |
| Плохая сеть | Всё работает офлайн, кроме live и голоса; live — оффлайн-фолбэк «дышите с записанным тактом» |
| Пользователь ушёл из сессии на 10-й секунде | Сессия `aborted`, не показывается как провал, не считается в статистике |
| Пейволл закрыт | Возврат туда, где был; ничего не блокируется навсегда |
| Свой звук не декодируется / битый файл | Тост «Не получилось прочитать файл — попробуйте mp3 или wav», слой не создаётся, ничего не ломается |
| Свой звук больше 12 МБ | Отказ с объяснением до сохранения; файл даже не читается в память |
| Свой звук с щелчком на стыке | Кроссфейд 350 мс; если файл короче 1 с — предупреждение «слишком короткий, будет заметен цикл» |
| Слой включён, но среда тихая из-за лимитера | Индикатор не нужен: лимитер работает всегда, пользователь может поднять громкость |
| Пользователь добавил чужой трек | Приписка о правах; технически продукт не распространяет файл (он локальный) |
| Жалоба «мне хуже» 3 раза подряд | Предложение остановиться, ссылка на помощь, автоматическое отключение напоминаний |

## 8. Definition of Done для v1.0

1. Первая сессия доступна за ≤2 тапа и ≤15 секунд, без регистрации.
2. Детекция дыхания: ≥85% корректных фаз в бытовых условиях, латентность <300 мс (см. тест-план).
3. Все сессии завершаются тишиной; ни одного «провального» состояния в UI.
4. Отпечаток показывает персональную частоту после 4 сессий.
5. Работает офлайн (кроме live/голоса), вес приложения ≤120 МБ, расход батареи ≤3%/10 мин сессии.
5a. Библиотека из ≥10 сред, микшер до 8 одновременных слоёв, сохранение своих сред; ни одного загружаемого аудиофайла (проверяется сетевым сниффером).
6. Ноль сторонних рекламных SDK; аудио не покидает устройство (проверено сетевым сниффером).
7. Все краевые случаи из §5 реализованы и покрыты QA-чеками.
8. Юридические тексты, дисклеймер «не медицинское изделие», региональные телефоны помощи.
9. Пейволл и оплата (App Store / Google Play / RuStore / ЮKassa-веб).
10. Дашборд продуктовых метрик из §6.

## 9. Локализация и культурные нюансы
- RU (база), далее EN, ES, PT-BR, DE.
- Никаких религиозных/эзотерических формулировок: «медитация» используется осторожно, основной словарь — «дыхание», «ритм», «покой».
- Голосовые гайды записываются носителями, но по умолчанию **выключены** — продукт работает без языка.
- Телефоны помощи — по региону, с проверкой актуальности раз в квартал.
